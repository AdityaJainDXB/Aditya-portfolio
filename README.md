## The idea behind the website

I didn't want to make a typical student portfolio with a list of achievements and a few project screenshots.

Instead, I wanted the website to feel more like an engineering workspace.

The visual direction combines:

- Apple's minimal and functional design philosophy
- Modern architectural layouts
- F1-inspired technical interfaces
- Large typography
- Lots of whitespace
- Small, subtle animations

The goal was to make the website feel clean without making it feel empty.

## How I built this

The website was built from scratch using Next.js and React.

I used Tailwind CSS for the layout and styling and Framer Motion for the animations.

Rather than creating every section individually, I used JavaScript/TypeScript data structures for things like projects and experiments. This makes it easier to add new projects without rebuilding the entire layout.

The site is also designed to be responsive, so the layout adapts between desktop and mobile screens.

### Tech stack

| Technology | Purpose |
|---|---|
| Next.js | Application framework |
| React | UI |
| TypeScript | Type safety |
| Tailwind CSS | Styling |
| Framer Motion | Animations |
| Lucide React | Icons |
| Vercel | Hosting |

## What I learned

This project taught me that a simple-looking website can actually involve a lot of design decisions.

Some of the biggest things I learned were:

- Structuring a Next.js project
- Building reusable React interfaces
- Using TypeScript with React
- Creating animations with Framer Motion
- Building responsive layouts with Tailwind CSS
- Working with Git and GitHub
- Debugging TypeScript errors
- Thinking about typography and spacing
- Designing a consistent visual system
- Preparing a Next.js application for static hosting

One of the more interesting problems I ran into was getting Framer Motion's animation variants to work correctly with TypeScript. The error initially looked confusing, but it helped me understand how strongly typed animation properties work.

I also learned that good UI isn't just about adding more effects. Sometimes removing things makes the design better.

---

## Challenges

The biggest challenge was getting the visual style to feel consistent.

I experimented with different layouts, colours and themes before settling on the current light design.

I wanted something that felt technical and modern without looking like a generic developer portfolio.

Another challenge was making sure the website stayed readable while using very large typography and relatively minimal content.
